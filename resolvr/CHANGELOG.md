# Changelog

## 1.3.2

- Resolvr 1.3.2: a rejected request now says why in the Log tab, and the sign-in form explains a session cookie the browser is not sending. See the [release notes](https://github.com/bassem-elsodany/resolvr-dns-dashboard/releases/tag/v1.3.2).

## 1.3.1

- Resolvr 1.3.1: choose how much it logs. New options `log_level`, `log_format` and `log_requests` in the Configuration tab; the healthcheck is no longer logged unless the level is `debug`. See the [release notes](https://github.com/bassem-elsodany/resolvr-dns-dashboard/releases/tag/v1.3.1).

## 1.3.0

- Resolvr 1.3.0: Technitium cluster support, with a scope on every panel. See the [release notes](https://github.com/bassem-elsodany/resolvr-dns-dashboard/releases/tag/v1.3.0).

## 1.2.0

- Resolvr 1.2.0. See the [release notes](https://github.com/bassem-elsodany/resolvr-dns-dashboard/releases/tag/v1.2.0).

## 1.1.0

- First release as a Home Assistant add-on. Resolvr appears in the sidebar and uses your Home Assistant sign-in, so it has no login of its own.
- The Technitium address and API token are set in the add-on's Configuration tab.
